# Martini Fixed Income Terminal

A quantitative fixed income research platform designed to analyze sovereign bond markets.

# Overview

Martini Fixed Income Terminal aims to replicate a specialized fixed income analytics platform by combining market data, quantitative models and macroeconomic analysis.

# Main Features

- Sovereign yield curve monitoring
- Treasury yield analysis
- Bond market statistics
- Duration and convexity calculations
- Spread analysis
- Quantitative indicators
- Automated fixed income insights

# Technology Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

# Objective

The objective of this project is to build a professional-grade fixed income analytics tool dedicated to understanding interest rate movements and bond market dynamics.
